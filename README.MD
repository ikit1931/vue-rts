# vue-rts

Прототип браузерной RTS на Vue. Canvas не используется.

## Как запустить

Нужен Node **20.19+** или **22.12+**.

```bash
cd vue
npm install
npm run dev
```

Адрес: **http://localhost:5173**.

## Docker

Из корня репозитория:

```bash
docker compose up --build
```

Адрес: **http://localhost:9999**.
