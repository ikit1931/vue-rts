Реализовать строительство зданий из панели навигации. Здания квадратные, разных размеров NxN.
Добавить характеристики персонажам (очки жизни, сила, скорость передвижения, скорость атаки) и зданиям (очки жизни).
Реализовать мгновенный спавн персонажей вблизи здания. Спавн доступен только из соответствующих зданий при их выборе.
Добавить панель навигации персонажа с действием самоуничтожения.
Добавить вражеских персонажей и здания. Врагов может быть много — это группы: группа 1, группа 2, группа 3 и т.д. Пока что ими тоже можно управлять.
Результат: здания строятся из панели навигации, персонажи и здания обладают характеристиками, персонажи спавнятся только у соответствующих зданий, у персонажа есть панель действий с самоуничтожением, объекты разделены по группам.
